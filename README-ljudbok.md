# AI för nybörjare — Ljudbok

Ordsynkroniserad ljudbok: **läs och lyssna samtidigt** på *AI för nybörjare* av Johan Falk (Natur & Kultur, version 2.0).

## Funktioner

- 🎧 **Ord-synk** — exakt det ord som sägs markeras medan du lyssnar. Klicka på ett ord för att hoppa dit.
- 📖 **Läs + lyssna** — full text per sida bredvid uppspelningen.
- ⚡ **Hastighet** — 1x / 1.2x / 1.5x / 2x (1x = normal).
- 🔁 **Loop** — upprepa aktuell sida.
- 📄 **Hoppa** — till vilken kapitel- eller sida som helst (t.ex. sid 12 → 52).
- 🔍 **Hitta ord** — sök ett ord i hela boken och hoppa exakt dit ordet sägs.
- 🔠 **Textstorlek** — enkelt förstora/förminska.
- 📱 **Mobil- och data-vänlig** — svart Spotify-inspirerad stil, bakgrundsuppspelning som på Spotify.
- 💾 **Offline/PWA** — fungerar som en installerad app, minns var du var och dina inställningar.

## Teknik

- Röst: Svensk Narrativ Röst via Fish Audio (OpenRouter) — naturligt djup, äkta svenska.
- Ljud komprimerat till 48 kHz mono för datavänlighet.
- Ordsynk: lokal Whisper-tidsstämpling per sida.
- Ren HTML/CSS/JS + Service Worker. Ingen byggkedja.
