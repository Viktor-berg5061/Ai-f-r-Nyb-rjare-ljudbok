# AI för nybörjare — Ljudbok

**Ordsynkroniserad ljudbok** av *AI för nybörjare* — Johan Falk (Natur & Kultur, v2.0).
Läs och lyssna samtidigt, på dator eller mobil.

📖 **Öppna ljudboken:** → **https://viktor-berg5061.github.io/Ai-f-r-Nyb-rjare-ljudbok/**

## Så använder du den

- **Lyssna + läs** — exakt det som sägs markeras i texten. Klicka på ett ord för att hoppa dit.
- **Hastighet** — 1× / 1.2× / 1.5× / 2×, och **loop** för att upprepa en sida.
- **Hoppa** — till valfri sida/kapitel (t.ex. sid 12 → 52).
- **Sök** — hitta ett ord i hela boken och hoppa dit exakt.
- **Textstorlek** — förstora/förminska enkelt.
- **Offline/PWA** — fungerar som installerad app, minns var du var och dina inställningar.

## För dig som vill enklare läsning

Hela texten finns också som ren textfil i repot: `AI för nybörjare 2.0 - TEXT.pdf`
(och per-sida text i appens `data/`). Använd gärna **1.2×-hastighet + ord-synk**
för att läsa medan rösten läser — bra för koncentration/inlärning.

## Teknik

- Röst: svensk narrativ röst (Fish Audio). Ljud komprimerat till 48 kHz mono.
- Ordsynk: lokal Whisper-tidsstämpling. Ren HTML/CSS/JS + Service Worker — ingen byggkedja.
